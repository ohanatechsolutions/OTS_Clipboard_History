# OTS Clipboard History branding

This folder contains reusable raster logo artwork for Ohana Tech Solutions' OTS Clipboard History application.

- `OTS_Clipboard_History_Logo.png`: 32×32 transparent PNG, exported directly from the user's watermark-free `clipboard_transparent.ico`.
- `../../src/OTS.Clipboard.History/Resources/App.ico`: original Windows icon embedded in the executable and installer.

**Use:** ICO for Windows app identity (installer, executable, tray, shortcuts). PNG for documentation, preview images and any UI surface that requires a PNG.

**Quality:** The supplied ICO has one native 32×32 image. Do not describe this as a high-resolution print-ready logo or upscale it for marketing banners. When the original high-resolution artwork becomes available, produce proper transparent PNG exports at 256×256 and 512×512 and a multi-size ICO (16, 24, 32, 48, 256).

Keep both formats visually consistent; do not use the older watermarked icon.
